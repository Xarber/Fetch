Privacy & source authorization

Submitted URLs are sent to your server. Original sources can observe its requests. Self-hosting does not establish permission to download media. Fetch does not bypass DRM or paywalls.

Updates

No releases have been published. Web updates offer a safe reload when a new application shell is installed. Public release discovery requires an authorized release endpoint.
