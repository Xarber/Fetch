THREE SIMPLE STEPS

Paste. Choose. Fetch.

Powerful processing, without a terminal in your everyday workflow.

  1. Start with a link

    Inspect an authorized media URL and see the available formats. Nothing is silently read from your clipboard.

  2. Make it yours

    Pick original quality, a compatible video, or an audio format. Your self-hosted worker handles downloading and processing.

  3. Save a verified file

    Follow the real queue state and save the result. Download and processing are separate stages; file integrity is checked before browser saving.

INDEPENDENT BY DESIGN

Small app.
Clear boundaries.

Fetch is built around ownership and a self-hosted processing service. It does not make source permissions or platform restrictions disappear.

  • Privacy has a place

    No advertisements or hidden analytics. Your configured server and the original source receive the requests needed to process your URL.

  • Your infrastructure

    X-Center is the default hosting target. No paid proprietary backend is required, and the web dashboard is optional for native operation.

  • Source you can inspect

    Original Fetch code is AGPL-3.0-only. Authenticated server users can request corresponding source from About Fetch after the administrator prepares it.

iPhone & iPad

SwiftUI source targets iOS 17+. Files, sharing and background transfers are implemented in source and still require native build and device validation.

View native build instructions

Self-hosted worker

The API and worker share a persistent queue. Docker configuration, authentication, source safety and processing limits are part of the project.

Read setup requirements

Know what is available.

There is no published IPA, App Store release or public distribution source yet. The browser currently verifies files up to 128 MiB in memory. Native transfer behavior, wider codec support, Docker deployments on additional architectures and remaining features need their own validation.

Only save content you are authorized to keep. Fetch does not bypass DRM or paywalls. Converting a lossy source to FLAC or WAV cannot restore lost quality.
